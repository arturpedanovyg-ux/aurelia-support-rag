# Order Changes and Cancellation
You can change the shipping address or cancel an order for free until it ships. Contact support as soon as possible, as same-day shipping can start within hours.
Engraved orders can be canceled only within 12 hours after placing the order.
Once an order has shipped, it cannot be canceled; you can refuse delivery or start a return when it arrives, subject to the returns policy.
We cannot add items to an existing order; please place a new order.
